# 轻盈 Lightly

一个中文热量与营养记录应用，可在电脑和手机浏览器使用。

**在线使用：[打开轻盈热量记录](https://2359831724-jpg.github.io/codex-test/)**

## 功能

- 每日饮食、早餐 / 午餐 / 晚餐 / 加餐记录，按条目指定的克重或毫升计算热量与三大营养素。
- 1,420 种食物与品牌参考条目，覆盖 8 个分类，包含鹅蛋、鸭蛋、地方小吃、肉蛋水产、菌菇、调味品与油脂，支持中文 / 拼音 / 英文搜索和常用份量选择。
- 普通蛋清同时支持「蛋清 / 蛋白 / 鸡蛋清 / 鸡蛋白」、拼音和英文搜索，区分生与煮熟状态，参考 52 kcal / 100 g，单个约 33 g 仅为份量示例。普通蛋清排在蛋清粉之前；原熟蛋清 ID、营养数值及历史记录保留。
- 肉类按常见部位细分，本轮补充 89 项禽类、96 项畜类、48 项水产部位，共 233 项。涵盖鸭腿／胸／小腿、鸡翅中／根／尖、猪梅花／肘／大排、牛腱／菲力／西冷、羊腿／排及鱼腹／鱼柳等；区分生熟、带皮去皮和肥瘦，按去骨去壳可食重量计量，营养为部位通用参考估算。整类查询（如鸭肉、鸡腿）可找到相关部位，具体部位查询不会混入整类或其他物种。
- 补充 132 项常见烹调状态，覆盖土豆／红薯／玉米／芋头／山药／南瓜、米面及多种蔬菜的蒸、烤、空气炸、煎炒、焖炖与土豆泥等做法。烤土豆区分无油／少油，土豆泥区分牛奶／黄油／芝士配方；按成品熟重和含油配方估算，实际额外配料可另行记录。
- 支持养乐多 / 養樂多 / 益力多 / Yakult 及伊利、蒙牛、安慕希、乐事、奥利奥、可口可乐等常见品牌名称搜索。品牌条目明确标注同类通用估算，未声称核验品牌包装标签；可点「按我的包装修正」预填后另存自定义条目。
- 统一别名搜索：提子 / 葡萄、奇异果 / 猕猴桃、车厘子 / 樱桃、地瓜 / 红薯等，支持拼音、英文、多词与全角输入。
- 饮食和运动记录弹窗列出全部匹配项目，可滚动到底部；取消原来只显示前 40 项的限制。
- 支持按包装每 100 克或每 100 毫升的营养标签添加自定义食物，保存到食物库重复记录，并随 JSON 备份迁移。克与毫升不自动转换；删除自定义食物不会删除已有饮食记录。
- 69 种运动及日常活动，按 MET、体重和时长估算运动净消耗，包括上肢功率车和坐姿上肢活动。
- 每日健身计划：查看周一到周日的热身、力量、有氧、活动度和恢复安排，每个动作提供组数／次数／时长、休息、步骤要点及哔哩哔哩教学视频搜索入口。教学链接打开精确动作搜索，未声称逐条审核或提供特定视频。
- 初始训练偏好按本次需求设置为健身房、新手、减少膝部负荷与冲击；常规 45 分钟，建议 10:00 开始，避开 17:00–18:00。每周三天轻负荷力量、两天低冲击有氧、一天轻缓活动、一天休息，可修改器械、时长、时段与动作偏好。高缺口目标不会自动加倍训练。
- 训练偏好及按日期完成标记随 JSON 备份保存；完成标记不自动产生运动消耗，记录按钮打开实际项目与分钟数的确认表单。旧版本备份会补默认偏好和空完成记录，原饮食、运动、身体档案与自定义食物保留。
- 身体档案包含身高、体重、年龄、生理性别、体脂率、日常活动水平及目标。
- 五种目标：温和减脂、保持状态、逐步增重、严格减脂塑形、极限减脂。严格与极限模式提供个性化热量缺口、蛋白质参考目标和每周力量／有氧记录进度；选择后保存身体档案即可启用。
- 基础代谢、日常总消耗、热量预算、BMI 和最近 7 天能量趋势。
- 按日期查看和删除记录；浏览器本地保存；JSON 备份导出 / 导入校验。
- 数据损坏时不会自动覆盖，先导出原始备份再决定重置。

## 直接使用

执行 `npm run export` 会生成 `dist/轻盈.html`。这是包含全部食物、运动数据和界面的单文件版本，复制或下载到电脑后，用现代浏览器打开即可，无需安装 Node.js 或启动服务器。记录仍保存在所用浏览器，建议定期导出备份。

## 计算方法

- **填写体脂率**：Katch–McArdle，`BMR = 370 + 21.6 × 体重(kg) × (1 − 体脂率 / 100)`。
- **未填写体脂率**：Mifflin–St Jeor，`BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 性别项`，男性 `+5`、女性 `−161`。
- **身高**用于无体脂率公式和 BMI；去脂体重公式本身不使用身高。
- **日常消耗**：`BMR × 日常活动系数`。活动水平指未单独记入运动日志的工作及日常活动。
- **每日预算**：保持为日常消耗；温和减脂减 300 kcal；逐步增重加 250 kcal；严格减脂塑形减 `min(日常消耗 × 20%, 500 kcal)`。预算不低于估算 BMR，界面显示实际缺口；严格模式 BMI < 18.5 时采用维持热量而不生成减脂缺口。BMR 只是估算，不代表个人适宜摄入量。
- **极限模式预算**：计划缺口为 `min(日常消耗 × 25%, 600 kcal)`，预算下限为 `max(估算 BMR, 男性 1,500 / 女性 1,200 kcal)`。低于 BMI 18.5 时不生成减脂缺口，预算为 `max(日常消耗, 预算下限)`；如果下限高于日常消耗，实际缺口为 0，界面明确说明。通用下限是软件保护阈值，不保证个体适宜摄入量；不通过饥饿或忽略下限扩大缺口。
- **严格模式营养参考**：蛋白质按体重 × 2 g，最多占基础预算的 35% 能量；脂肪占 25%，碳水补足剩余热量。三大营养素热量合计等于基础预算，运动加回不自动提高蛋白质参考目标。原三种模式仍使用体重 × 1.2 g 的蛋白质参考。
- **极限模式营养参考**：蛋白质按每公斤体重 2.2 g，仍受基础预算 35% 能量上限约束；脂肪占 25%，碳水补足余量。训练参考沿用每周 3 天力量和 150 中等强度等效有氧分钟，运动净消耗仍完整加入当天可摄入预算。
- **严格模式训练参考**：每周 3 天力量训练、150 分钟中等强度等效有氧。进度按所选日期所在周的周一到周日统计；同一天已知力量活动累计至少 20 分钟计 1 天。有氧／球类／户外／日常活动类别按记录时 MET 折算：3 ≤ MET < 6 为 1 倍分钟，MET ≥ 6 为 2 倍；力量、身心、低强度及未知活动不计入有氧。这是记录进度，不代表训练质量或效果保证。
- **运动净消耗**：`max(MET − 1, 0) × 3.5 × 体重(kg) / 200 × 分钟`，扣除同一时段静息消耗。
- **当日剩余预算**：`每日预算 + 当日运动净消耗 − 当日饮食摄入`。

公式面向 18 岁以上的一般成人，仅作估算参考。食品烹调及品牌、活动强度与个体差异均会影响实际结果。食物按条目每 100 克或每 100 毫升显示，属于常见食材参考值，不是官方食品数据库认证数据。品牌名称索引沿用最接近的通用品类，并显示来源品类及未核验说明；养乐多条目暂用含糖乳酸菌饮品通用值，按 1 mL≈1 g 估算，并非品牌专属标签值。实际包装食品以手中标签为准。MET 为常见活动估算。详见 `src/data.ts` 与 `src/foods-branded.ts` 说明。已记录运动保留运动时体重，之后修改档案不会重算原记录。历史趋势图的日常消耗使用当前档案估算。

## 数据与隐私

无后端、账号或跨设备同步；所有记录保存在当前浏览器的 `localStorage`，键名 `calorie-studio:v1`。不预填虚构的饮食和运动记录。初始 2,000 kcal 为明确标注的参考预算，保存身体档案后更新。

清除浏览器数据、切换浏览器或设备都会使记录不可见。请在「身体档案」导出 JSON 备份；导入会校验数据并在用户确认后替换当前身体档案、记录、自定义食物、训练偏好及完成日期。更新前不含自定义食物或训练字段的旧备份仍可导入，原始身体档案与记录会保留。旧记录缺少单位时仍按克读取，不会重算既有热量；新备份保留克／毫升单位及训练字段。备份包含个人身体信息，应妥善保管。

## 网页发布

公开网站由 GitHub Pages 提供，发布源为本仓库 `gh-pages` 分支根目录。该分支只包含生成的 `index.html` 与 `.nojekyll`；应用源代码保存在 `main`。修改源代码后执行 `npm run export`，将 `dist/轻盈.html` 作为 `index.html` 更新到 `gh-pages` 后才会更新在线版本。个人记录不上传 GitHub。
